## 2. FFmpeg

- **Project**: [https://ffmpeg.org](https://ffmpeg.org)
- **Binary Distribution**: Built by [gyan.dev](https://www.gyan.dev/ffmpeg/builds/) (Version 7.1.1 essentials build)
- **License**: GNU General Public License v3.0 (GPLv3) / GNU Lesser General Public License (LGPL)
- **Copyright**: `Copyright (c) 2000-2025 the FFmpeg developers`

FFmpeg is a leading multimedia framework to decode, encode, transcode, mux, demux, stream, filter and play pretty much anything that humans and machines have created.

LockscreenGif executes the standalone `ffmpeg.exe` binary via external command-line process invocation (`System.Diagnostics.Process`) to analyze video files and generate high-fidelity image sequences.

The source code for FFmpeg can be obtained from [https://ffmpeg.org](https://ffmpeg.org) or [https://www.gyan.dev/ffmpeg/builds/](https://www.gyan.dev/ffmpeg/builds/).
